Git

1.git安裝,官網下載https://git-scm.com/
2.命令提示字元或使用git bash(這裡就可以用linux語法)
3.指令git config先設定使用者名稱和email
4.在欲做版控的資料夾下，先用git init指令進行初始化

指令：非git開頭的指令,主要是linux指令,有可在win替代的寫在斜線後方
pwd/cd：目前位置
ls/dir：列出所有檔案及資料夾
ls -l:列出檔案及資料夾（包括詳細資料）
ls -lh
cd：前往
clear/cls：清空畫面
q：有End出現可以使用這個離開
touch/type nul > filename.ext：建立檔案
rm filename.ext/del filename.ext：刪除檔案
rm -rf dirname/rmdir dirname：刪除資料夾
cp filename.ext　new_filename.ext：複製檔案
cp -r dirname new_dirname：複製資料夾
mv filename.ext dirname：移動檔案
mv filename.ext new_name.ext：更改檔名
mkdir dirname：建立資料夾
cat filename.txt：看檔案內容

git config --global --list 可以查詢使用者名稱和email
git config --global user.name "欲修改名稱"
                    user.email "同上"
git init：初始化（進到要進行版本控制的資料夾後使用，初始化完成後，會變成master）
git log：查詢版本管理紀錄
git log --oneline：版本管理紀錄以一行一行顯示
git status：查看目前狀態
git add filename.ext：將單一檔案添加版本管理檔案（尚未commit）
git add ./*.md：所有檔案添加/某檔案類型全部添加
git commit -m "添加敘述"　（要注意沒有設定使用者名稱和email無法成功commit）
				
git diff filename.ext：比較修改前後的檔案內容（不輸入檔名會顯示所有更改的檔案內容）
git show commit_id：顯示commit的修改紀錄，會顯示修改後的檔案內容
gitk：版控歷程紀錄視窗畫面
git blame filename.ext：顯示每一行內容的<sha1 ID>、作者、時間...等資訊
 

新增、修改、刪除、變更檔案名稱（每次的變更都使用add）
1.新增檔案：add → commit
2.修改檔案：add → commit
3.刪除檔案：add/rm → commit
4.變更檔名：add → commit


Git資料模型

．執行時會發生
工作目錄（Working directory）→ add → 暫存區（Index(cache)）→ commit → 本地數據庫（Local repository）
→ push → 遠端數據庫（Remote repository 如GitHub...）

．Pull時會發生
Remote repository → Local repository → Working directory

．Fetch時會發生（單純下載至本地數據庫）
Remote repository → Local repository

．Checkout時會發生
Local repository → Working directory
